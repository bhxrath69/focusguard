# FocusGuard (Manifest V3)

Pomodoro timer (Phase 1) + architecture for future procrastination detection.

## Load unpacked in Chrome
1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the `focusguard` folder

## Test Phase 1
- Use the popup to start/pause/reset pomodoro
- Notifications should appear when work/break sessions end
